# hangdah.github.io

个人技术文档、学习记录与开源项目主页。

## 预览说明

本站使用 GitHub Pages 的 Jekyll 构建功能。不要直接双击打开源码中的 `index.html`，否则浏览器会把 Front Matter 和 Liquid 模板当作普通文字显示。

- 线上页面：<https://hangdah.github.io/>
- 已安装 Jekyll 时，本地运行 `jekyll serve`，再访问终端提示的本地地址。

完整的浏览、写作、分类管理、项目配置和发布方法见[《主页使用与维护指南》](_docs/how-to-add-docs.md)。

# hangdah.github.io

个人技术文档、学习记录与开源项目主页。站点使用 Astro 构建，设计参考开源主题 [AstroPaper](https://github.com/satnaing/astro-paper)。

## 本地运行

需要 Node.js 22.12 或更高版本，并建议使用 pnpm：

```bash
corepack enable
pnpm install
pnpm dev
```

生产构建与预览：

```bash
pnpm build
pnpm preview
```

线上页面：<https://hangdah.github.io/>

完整的写作、分类管理、项目配置和发布方法见[《主页使用与维护指南》](_docs/how-to-add-docs.md)。
